# repwise-pwa
## iPhone quick start

Open `https://chittesh24.github.io/repwise-pwa/` in Safari (include the final slash). If it fails, verify **Settings → Pages** in this repository and wait until the latest `main` branch/root deployment completes. If an old or blank page remains, export any local workout backup, then remove this site's saved data under **Settings → Safari → Advanced → Website Data** and reopen the URL. See [DEPLOYMENT.md](DEPLOYMENT.md) for details.

The app uses one PWA shell with app-style screens. Primary navigation is in the bottom bar; secondary screens are in **More**. After updating the source, publish the changed files to the `main` branch for GitHub Pages to show them on iPhone.
